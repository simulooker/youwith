학습 원리

작은 네트워크가 XOR을 배우는 방법

경우 1은 입력 (0, 1), 경우 2는 (1, 1)입니다. 같은 네트워크가 두 입력을 어떻게 다르게 예측하는지 비교합니다. 네 표본 전체의 평균 손실로 학습한 결과를 단계별로 확인하세요.

  1. 순전파 가중치·편향과 tanh/sigmoid를 통과합니다.
  2. 역전파 평균 BCE 손실의 기울기를 구합니다.
  3. 갱신 학습률 0.5로 1회·200회·4,000회 학습한 기록을 비교합니다.

숫자는 실제 계산해서 저장한 결과입니다. 브라우저에서는 학습하지 않습니다. 선의 두께는 가중치 크기, 구의 밝기는 활성값 크기입니다. 이동 점은 계산 순서이며 실제 전자가 아닙니다.

이 경우의 설정

입력 2 → 은닉 4 → 출력 1 · tanh / sigmoid · 평균 BCE

계산해 저장한 기록을 재생합니다.
